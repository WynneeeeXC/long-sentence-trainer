## 为什么做这个

考研英语阅读里真正卡住人的不是单词，而是**长难句**。传统做法是：手机复制句子 → 贴到 Word → 开翻译软件 → 看了译文还是不懂考点 → 下次遇到还是不会。

这个项目把流程闭环起来：

```
粘贴句子 → AI 结构化分析（结构/考点/逐段翻译/整句翻译/技巧）
        → 手动确认考点 → 存入 SQLite
        → 复习模式（先自己翻译，再看答案，自评表现）
        → 统计页定位薄弱考点
```

核心原则：**先拆结构，再翻译**。结构不懂，翻译就是背答案。

## 功能总览

| 页面 | 功能 |
|---|---|
| 分析页 | 单句分析 + 批量导入（自动切句，最多 10 句）；**可先写自己的译文，AI 一针见血点评**；自动挑出值得背的固定表达，一键收录进短语本；考点 chips 可手动增删后保存；自动查重 |
| 快捷收录 | 手机专用轻量页：粘贴即分析即保存，扇贝阅读/真题复制句子后切过来用 |
| 句子库 | 关键词搜索 + 考点筛选；来源/时间/复习次数展示；CSV 导出；**取消收录（移入回收站，7 天后自动清除）** |
| 详情页 | 结构拆解、翻译、技巧、我的译文与 AI 点评；**复习历史（每次译文+点评+自评）**；本句短语；笔记；同类考点推荐 |
| 复习模式 | 随机抽句 → 先自己翻译 → **AI 点评（对比你上次的译文，指出进步/退步 + 高级表达）** → 自评记录 |
| 短语本 | AI 挑出的固定表达一键收录 + 手动添加；删除（进回收站）、标记已掌握 |
| 出题页 | 短语级三种题型 + **句子级英译中（考研翻译题）**；手写题提交后 **AI 评分 + 一针见血点评 + 更地道参考答案** |
| 回收站 | 被取消收录的句子/短语都在这里，可恢复或彻底删除，**超过 7 天自动清除** |
| 文章精读 | **上传整篇阅读图片（Windows 内置 OCR）或粘贴文字** → 熟词僻义、外刊高频词组、段落主旨、全文翻译、中心思想+作者态度、**5 道考研选择题** |
| 统计页 | 句子总数、复习覆盖率、考点分布、复习表现、薄弱考点排行、短语掌握进度 |

**固定考点枚举（20 项细分版）**（AI 输出自动归一化，统计才可靠）：

```
定语从句 / 状语从句 / 名词性从句
/ 非谓语-不定式 / 非谓语-动名词 / 非谓语-现在分词 / 非谓语-过去分词
/ 独立主格 / 倒装句 / 强调句 / 省略句 / 插入语
/ 分隔结构 / 平行结构 / 虚拟语气 / 被动语态
/ 比较结构 / 代词指代 / 逻辑连接 / 作者态度
```

**离线演示模式**：没有 API Key 时自动进入关键词启发式分析，界面可完整跑通；配置 Key 后自动切换真实 AI。

## 技术栈

- 存储：SQLite（零配置，单文件）

## 快速开始

### 1. 克隆 & 安装

```bash
git clone https://github.com/WynneeeeXC/long-sentence-trainer.git
cd long-sentence-trainer
pip install -r requirements.txt
```

### 2. 配置 API Key

复制 `.env.example` 为 `.env`，填入你的 Key：

```bash
cp .env.example .env   # Windows: copy .env.example .env
```

```
DEEPSEEK_API_KEY=sk-你的key
```

> Key 在 [platform.deepseek.com](https://platform.deepseek.com) 申请。`.env` 已被 gitignore，不会提交到仓库。

### 3. 启动

```bash
python app.py
```

浏览器打开 http://127.0.0.1:5000

> 想先不花 token 体验界面？`set MOCK=1` 后启动即进入离线演示模式。

### 4. 手机访问（同一局域网）

电脑开热点或连同一 WiFi 后：

1. 电脑上运行 `ipconfig`，找到当前网络 IPv4 地址（如 `192.168.137.1`）；
2. 手机浏览器打开 `http://<电脑IP>:5000`；
3. 手机浏览器菜单里「添加到主屏幕」，之后像 App 一样点开（PWA）。

> 该工具是纯本地运行，数据存在电脑上，只有局域网内能用。
> **后端没启动（app.py 没运行）手机就打不开**——这是本地应用的正常表现。
> **热点 IP 每次开热点可能变化**：a) 想让地址固定，可在 Windows 网络设置里给网卡设静态 IP（子网掩码 255.255.255.0，网关填热点地址）；b) 想随时随地访问（电脑不在身边也能用），用内网穿透（cpolar/ngrok/frp）或 Tailscale/ZeroTier 组虚拟局域网，获得固定地址。
> 悬浮窗「检测复制自动收录」需要安卓原生无障碍 App，网页版做不了；替代方案：在扇贝阅读里复制句子后，切到本工具的「快捷收录」页粘贴即可。

## 使用流程

1. **分析**：把读不懂的句子粘进「单句分析」，AI 返回结构拆解、考点、逐段翻译、整句翻译、翻译技巧；**先填自己的译文，AI 会逐条指出问题并给更地道的版本**；考点可以点击增删，确认后保存；「收录」AI 挑出的固定表达进短语本。
2. **批量**：从扇贝阅读 / 真题阅读复制整段，粘贴进「批量导入」，自动切句分析，一键全部保存（自动跳过重复）。
3. **快捷收录（手机）**：复制句子后直接切到「快捷收录」页，粘贴 → 分析 → 保存，一条龙。
4. **复习**：先逼自己翻译，AI 会**对比你上次的译文**告诉你进步/退步在哪，并给出高级表达；最后诚实自评。
5. **出题**：「出题」页四种模式——英选中文、英译中听写、中译英造句、**英译中（句子翻译，模拟考研翻译题）**；手写题提交后 AI 评分并指出问题、给出更地道参考答案。
6. **回收站**：取消收录的句子/短语先进回收站（7 天内可恢复），超过 7 天自动清除；也可在回收站里彻底删除。
7. **文章精读**：上传整篇阅读（图片自动 OCR 或直接粘贴文字），得到熟词僻义、高频词组、段落主旨、全文翻译、中心思想与作者态度，再做 5 道考研选择题。
8. **统计**：看看哪个考点翻车最多，针对性补。

## 复习与统计逻辑

- 抽句策略：`ORDER BY 复习次数 ASC, RANDOM()` —— 优先复习没练过的句子
- 薄弱考点：复习时自评为「完全不会 / 意思对但表达差」的句子，其考点累计翻车次数排行
- 查重：同句原文只保存一条，避免库被刷脏

## 机器学习作业扩展

这个项目天然积累**带标注数据**，做课程作业可以直接用：

1. **文本分类**：句子库 → `导出标注数据（CSV）`，把 `exam_points` 当多标签，训练一个小分类器（sklearn 的 OneVsRest + TF-IDF 即可）来预测新句子考点。
2. **Embedding + 相似度**：用 `sentence-transformers` 对句子做向量化，找结构相似的句子（`all-MiniLM-L6-v2` 中文句也够用）。
3. **聚类**：对句子向量做 K-Means，看句子自动分成几类、每类对应什么结构。
4. **评估**：AI 翻译 vs 你自己的翻译，算 BLEU（`nltk.translate.bleu_score`）或让 AI 打分，观察"意思对但表达差"是不是普遍现象。

CSV 字段：`id, stem, source, exam_points, full_translation, created_at`
